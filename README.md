# Wingate Jones

Data engineer in New Orleans. I build data platforms for institutional finance: vendor ingestion, lakehouses, and the tooling that proves every file landed intact. Mostly Python and Rust, with Apache Spark and Apache Iceberg underneath.

On the side I formalize mathematics in Lean 4 and write graphics code in C++ and Vulkan.

### Projects

- **[Erdős Lab](https://g8r-b8.github.io/erdos-lab)**: research notes on open Erdős problems. Includes a merged Lean 4 contribution to Google DeepMind's [formal-conjectures](https://github.com/google-deepmind/formal-conjectures/pull/6605).
- **[erdos132-lean](https://github.com/g8r-b8/erdos132-lean)**: a sorry-free Lean 4 / Mathlib formalization of a 4/3 upper bound for Erdős #132.
- **[math-notes](https://github.com/g8r-b8/math-notes)**: expository notes on quaternions and octonions, the Monster group, and the Erdős–Nešetřil conjecture.
- **[house-lab](https://github.com/g8r-b8/house-lab)**: real estate listing search and ranking with a house-hack affordability model (Python, DuckDB, FastAPI, SvelteKit).
- **[octonion_fractals](https://github.com/g8r-b8/octonion_fractals)**: 39 ray-marched octonion, quaternion, Mandelbulb and Mandelbox fractals in one Vulkan binary.
- **[vulkanTemplate](https://github.com/g8r-b8/vulkanTemplate)**: a Vulkan 1.3 / C++20 renderer with a chapter-per-step reference.
- **[pathLab](https://github.com/g8r-b8/pathLab)**: a citation-weighted index of research papers across quantitative graduate programs.
- **[frontierLab](https://github.com/g8r-b8/frontierLab)**: a strategy game about founding a frontier AI lab.
